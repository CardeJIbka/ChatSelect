# Chat Select

A small client-side mod that lets you select and copy text in the Minecraft chat with the mouse, the way you would in any text editor.

Vanilla chat doesn't let you copy anything. Want to grab a coordinate, a command or a link someone posted? You end up retyping it. This mod fixes that.

## How to use

Open the chat and:

- **Click and drag** over the text to select it. Dragging above or below the chat scrolls it for you.
- **Double-click** to select a word.
- **Triple-click** to select a whole message, even if it wraps over several lines.
- **Ctrl+Shift+A** selects everything in the chat history.
- **Ctrl+C** copies the selection to your clipboard.

Clicking a link or a clickable command without dragging still works as usual.
